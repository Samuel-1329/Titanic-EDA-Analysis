# Titanic Exploratory Data Analysis

## Objective
Perform Exploratory Data Analysis (EDA) on the Titanic dataset to identify patterns, trends, and factors affecting passenger survival.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Findings
- Female passengers had higher survival rates.
- First-class passengers were more likely to survive.
- Higher fares were associated with survival.
- Most passengers were between 20 and 40 years old.
- Passenger class strongly influenced survival.

## Outcome
Successfully performed Exploratory Data Analysis and extracted meaningful insights from the Titanic dataset.
